# v2026.10.0

Previous version: [v2026.9.0](./v2026.9.0.md)

## Enhancements

**Added new FOTA status error messages**

Added more FOTA device progress error messages to better reflect the current update status on the device.

**New valid FOTA states**

Added new valid FOTA states during the waiting stage to make the update process more flexible and allow FOTA finish successfully for custom cases.

**Improved LwM2M Bootstrap tab interface**

Improved the LwM2M Bootstrap tab in the domain management panel for a better user experience.

**User activity logs documentation**

Added a user guide section for user activity logs. The new documentation describes available functions and is available under: [User activity logs](https://{{coiote_server}}/doc/user/platform-administration/how-to-guides/users-and-access/review-user-activity-logs.md)

## Bug Fixes

**User filters**

Fixed an issue that caused an error when filtering users if some accounts in the domain had not logged in to the platform after creation.

**Report generation freeze**

Fixed an issue that could cause the report generation process to freeze.

**Multicomponent FOTA improvement**

Fixed an issue that could cause the non-blocking version of Multicomponent FOTA to fail due to observations.
