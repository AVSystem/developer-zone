# v2026.12.0

Previous version: [v2026.11.0](./v2026.11.0.md)

## Features

**New FOTA progress error types**

Added new error types with clearer messages for FOTA progress issues. This helps users better understand why a timeout or interruption occurred during a firmware update.

## Enhancements

**nRF Cloud integration update**

Updated the nRF Cloud location services integration to use Organization Auth Tokens. Service Tokens are no longer supported due to changes introduced by nRF Cloud.

**Improved nRF Cloud API communication**

Updated communication with nRF Cloud endpoints to match recent API changes. More details are available in the guide: [nRF Cloud](https://{{coiote_server}}/doc/user/integrations/how-to-guides/configure-nrf-cloud-integration.md)

**Monitoring and Data Integration Center telemetry improvements**

Improved processing of telemetry collection and forwarding in Monitoring and Data Integration Center features.

**Improved CSV device import**

Improved CSV device import to handle larger batches of devices reliably. The import process now also provides more meaningful log messages.
