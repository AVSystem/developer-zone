# v2026.13.0

Previous version: [v2026.12.0](./v2026.12.0.md)

## Enhancements

**Device CSV Import**

Improved device CSV import to correctly process files that include a byte order mark (BOM).

**Firmware file download stopped after FOTA failure**

Improved FOTA with PULL delivery method so that server responds with error in case device tries to still download firmware file after the update fails. This helps avoid unnecessary file transfers after issues such as message timeout.

**Improved automated job scheduling**

Improved scheduling of automated periodic jobs. Now the process is enhanced and better optimised which should reduce blocking issues and the need for retries.
