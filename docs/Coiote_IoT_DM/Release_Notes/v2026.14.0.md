# v2026.14.0

Previous version: [v2026.13.0](./v2026.13.0.md)

## Enhancements

**Software name displayed in SOTA instance selection**

Added the reported software name to the selection of Object /9 instances in the SOTA interface. The software name is displayed alongside the LwM2M path when available.

**Firmware file name displayed in FOTA task details**

Added the firmware file name to the task parameters of device and group FOTA tasks. This makes it easier to identify the file used for an update.
