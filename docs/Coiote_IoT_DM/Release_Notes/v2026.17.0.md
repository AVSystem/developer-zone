# v2026.17.0

Previous version: [v2026.16.0](./v2026.16.0.md)

## Enhancements

**Default user ordering in Users Management**

Users in Users Management are now ordered by username by default.

**Improved error messages**

Improved various error messages to prevent internal exception details from being displayed.

**Unnamed tasks in task lists**

Tasks created without a name are no longer displayed as "anonymous". Instead, the task list indicates that the name field is empty.

## Bug Fixes

**Restricted access to alerts in Operation Center**

Fixed an issue that allowed alerts to be accessed and edited outside the intended feature functions.
