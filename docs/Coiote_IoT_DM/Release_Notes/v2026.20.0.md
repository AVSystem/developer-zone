# v2026.20.0

Previous version: [v2026.18.0](./v2026.18.0.md)

## Features

**CSV export of device logs**

Added an option to export device logs to a CSV file based on the selected time range and filters.

## Enhancements

**Old LwM2M Bootstrap panel removed**

Removed the old LwM2M Bootstrap panel. From now on bootstrap settings are available only in the new section of Domain Management.

**Old Device Inventory panel removed**

Removed the old Device Inventory panel after the completion of the migration to the new view.

**Input length validation**

Added missing length validation to input fields across various areas of the platform.

**Improved spacings**

Improved spacing in several areas of the platform interface for a more consistent user experience.

**Improved error messages**

Improved several error messages to remove unnecessary technical details and make them clearer for users.
