# v2026.21.0

Previous version: [v2026.20.0](./v2026.20.0.md)

## Enhancements

**Cleaner user activity history**

Removed unused actions from User activity to keep the activity history based solely on relevant user actions.

**Scheduled LwM2M operations by default**

Changed the default Apply option for LwM2M operations in LwM2M Objects panel from Apply immediately to Schedule

**Updated location source in Device Center**

Updated the location source label in Device Center to clearly indicate when location data comes from the LwM2M Location object (/6).

**Updated log in as a client function**

The Log in as a client function now supports impersonation one level at a time. User activity logs were also improved to provide clearer information about impersonation actions.

## Bug Fixes

**Session revocation after logout**

Sessions are now revoked immediately after logout.
