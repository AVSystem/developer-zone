# v2026.6.0

Previous version: [v2026.5.0](./v2026.5.0.md)

## Features

**German language support**

German has been added as a new platform language option.

## Enhancements

**Faster device CSV import**

Improved the performance of device CSV import operations. Large imports should now complete much faster.

**New default value for Device Logs period**

The default Device Logs visibility period in Device Center has been changed to 1 hour. This significantly shortens initial loading times when devices generate high log volumes.

**Swagger as the supported REST API documentation**

Swagger is now the only supported format for Coiote DM REST API documentation.
