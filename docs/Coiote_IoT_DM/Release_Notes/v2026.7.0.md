# v2026.7.0

Previous version: [v2026.6.0](./v2026.6.0.md)

## Features

**EST integration certificate management**

Added support for managing certificates used in EST integration. Users with proper privileges can configure certificates for mTLS communication, choose authentication methods for selected endpoints, and set the signing CA certificate as trusted.

## Enhancements

**Improved device logs performance**

Improved device logs performance, so logs should load faster and have less impact on the installation.
