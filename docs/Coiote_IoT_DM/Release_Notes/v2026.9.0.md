# v2026.9.0

Previous version: [v2026.7.0](./v2026.7.0.md)

## Features

**User activity Logs**

Added new views and reporting options for tracking user activity across the platform. Administrators and users with proper permission can browse, filter, and export activity logs within their organization.

## Enhancements

**Removed redundant ACK messages during CoAP block transfer**

Identified and removed unnecessary ACK message sent to devices during CoAP block transfer communication.

**Improved FOTA progress statuses**

Improved FOTA progress reporting in Device Center. A failed additional firmware version read (Lwm2m path: /3/0/3/) no longer marks the FOTA process as failed and is now shown as information in the UI.
